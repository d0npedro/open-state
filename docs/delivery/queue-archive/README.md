## Regel

- Aktive Arbeit: nur [`docs/NEXT_STEPS_QUEUE.md`](../../NEXT_STEPS_QUEUE.md)

- Inhalt archivieren, nicht löschen (Commit-Hashes bleiben nachschlagbar)
