# Journal-Archiv (Domain-Loops)

Ältere Iterationsprotokolle der Multi-Loop-Domain-Journals. **Kein Pflichtlesen** im Standard-Agenten-Lauf.

## Regel (Q-303 / Anti-Growth)

| Regel | Wert |
|-------|------|
| Aktives Journal | `docs/loops/<domain>-JOURNAL.md` |
| Max. aktive Iterationen | **15** (neueste zuerst) |
| Orientierung Zeilen | ideal ≤ ~200–350 Zeilen aktiv |
| Archivierung | ältere Blöcke hierher, **nicht löschen** |
| Format pro Iteration | kurz: Was / Dateien / Story / Build / nächster Hinweis (kein Feature-Roman) |
